# Ідея проєкту
Для нашого проєкту ми обрали саме акції компанії Apple, адже вважаємо дану компанію однією з найстабільніших та найбільш прибуткових компаній у світі, що позитивно відображається на цінах їхнії акцій. Також, їхні акції є одними з найбільш використовуваних на трейдерському ринку та мають велику популярність.
# Інструменти аналізу
Для нашого аналізу ми використовували наступні бібліотеки: Pandas, Numpy, Matplotlib та yfinance. Пандас + нампай - для зручного виведення та роботи з данними, yfinance - для вивантаження даних, Matplotlib - для графічного виведення даних. Також були використані наступні функції даних бібліотек: rolling.mean() - для обрахунків сковзного середнього, np.where() - для швидких обчислень в межах таблиці без використання циклів for або while, .diff() - для фільтрації періодів та визначення точок входу/виходу з ринку через різницеві методи.
